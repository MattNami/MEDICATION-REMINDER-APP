# 💊 Medication Reminder App

A native Android application project focused on helping users manage medication reminders through a dedicated mobile experience.

> **Project Status:** 🚧 In Development

---

## 📌 Overview

**Medication Reminder App** is an Android-based mobile application project designed around the concept of medication reminders.

The project provides a foundation for developing a user-friendly mobile experience where medication-related reminder functionality can be implemented and expanded as the application evolves.

The repository is structured as a standard Android/Gradle project using Java DSL configuration.

---

## 🎯 Project Objectives

The main objectives of this project are to:

* 💊 Provide a dedicated mobile application for medication reminders
* ⏰ Support medication reminder functionality
* 📱 Create a simple and accessible Android user experience

* 🚀 Provide a foundation for future medication-management features

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/MattNami/MEDICATION-REMINDER-APP.git
```

### 2. Open the Project

Open the cloned project using **Android Studio**.

### 3. Sync Gradle

Allow Android Studio to synchronize the Gradle configuration and download the required project dependencies.

### 4. Build the Application

From Android Studio, select:

**Build → Make Project**

Or use the Gradle wrapper:

```bash
./gradlew build
```

For Windows:

```bash
gradlew.bat build
```

### 5. Run the Application

Connect an Android device or start an Android Emulator, then run the application from Android Studio.
